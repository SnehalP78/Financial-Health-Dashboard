# Overview -
The Financial Health Report Dashboard is an interactive Power BI dashboard designed to provide a comprehensive view of an individual's or organization's financial performance. It enables users to monitor income, expenses, assets, liabilities, debt, savings, and investments through dynamic visualizations, helping them make informed financial decisions. The dashboard offers city-wise financial analysis, expense categorization, debt distribution by occupation, investment insights, and savings trends in a single, easy-to-understand interface.
# Features -
📊 Financial Overview – Displays key financial metrics including Total Income, Total Expenses, Debt, Net Worth, and Savings.
🏙️ City-wise Analysis – Compare financial performance across multiple cities using an interactive slicer.
📈 Assets vs Liabilities Comparison – Visualize assets and liabilities for each city to evaluate financial stability.
📉 Income vs Expense Trend – Track yearly income and expense trends to monitor financial growth.
💰 Expense Category Analysis – Analyze spending across categories such as Rent, Food, Transportation, Shopping, Utilities, and Entertainment.
💳 Debt Analysis – View debt distribution across different occupations to identify financial obligations.
💵 Savings Trend – Monitor savings over time to understand financial progress.
📊 Investment Analysis – Explore the distribution of investments across different cities using a doughnut chart.
🎛️ Interactive Dashboard – Filter and explore data dynamically using slicers and interactive visuals.
📌 Data-Driven Insights – Gain actionable insights to improve budgeting, spending habits, and overall financial planning.
